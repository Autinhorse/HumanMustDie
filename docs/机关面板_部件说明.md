# 机关面板 · 部件说明

三种面板（弹簧板 / 尖刺板 / 推板）× 三个等级，全部由
`tools/blender/build_boards.py` 程序化生成。这份文档是**改外观时的对照表**：
看图 → 找部件名 → 找到控制它的参数。

---

## 怎么用

**看：**

```
python tools/preview_board.py spikes 1      单独看一块
python tools/preview_board.py all           九块全出一遍
python tools/preview_board.py spikes 1 --game   顺便刷新 Godot 资源，进游戏能看到
```

出图在 `renders/parts/`：

- `board_<类型>_<等级>_parts.png` —— **带部件名标注**，蓝色是固定件、红色是活动件
- `board_<类型>_<等级>.png` —— 干净的渲染图

**改：** 所有比例数字都在 `tools/blender/build_boards.py` 顶部的 `PARAMS` 表里，
每一项都有注释。几何代码只读这张表，不再写死数字，所以改形状不用看下面的代码。

单位一律是**格**：`1.0` = 一个格子的边长（游戏里 `cell_size = 2` 米），
所以 `0.05` = 10 厘米。板子按 1×1 格建，x/y 范围 ±0.5，z = 0 是地面。
带 `_step` 的表示"每升一级加多少"。

**一句话提需求的格式**（这样我改起来没有歧义）：

> `Groove` 太宽，减一半
> `Bolt` 往外挪一点，别压在金框上
> `Arrow` 再大 20%
> 尖刺的 `cap_fill` 太小，槽底露太多

## 三种板共用的外框

从外到内的层次是：金框 → 暗凹槽 → 内板。

**没有石缘**：板子直接坐在地面上，金框外沿就是格子边（`gold_outer = 0.5`）。

| 部件 | 是什么 | 主要参数 |
|---|---|---|
| `Gold` | 金框，外沿顶到格子边 | `gold_outer` / `gold_inner` / `gold_top` |
| `GoldLine` | 二级起，金框内侧的一道暗金细线 | `goldline_width` |
| `Groove` | 金框内侧的**暗凹槽** | `groove_width` / `groove_below` |
| `Bolt` / `BoltT` | 四角的**方形**铆钉，`BoltT` 是顶上的收口 | `bolt_size` / `bolt_cut` / `bolt_body_h` / `bolt_cap_h` / `bolt_cap_scale` |

`Bolt` 是正方形，外角正好落在格子的角上（外沿和金框外沿齐平）。
朝格子内侧的那个角切掉一个斜角，下刀位置在两条边的 `bolt_cut`（现 1/3）处。
`BoltT` 用同一个轮廓按 `bolt_cap_scale` 缩小，只往内缩，外角仍然贴着格子边。

> `Groove` 是这套外观的关键。设计图里金框和内板之间有一条明显的暗线，
> 靠它把两层分开；去掉以后整块板从白到浅灰连成一片，完全没有层次。

内板上表面的高度是 `plate_top`（现 0.062）。**所有活动件静止时都对齐到这个高度** ——
"没弹出来时和表面平齐"就是靠它保证的。

## 弹簧板 `spring`

弹出侧（模型的 -Y）有一条结构，板子绕它翻起；箭头平嵌在板面里。

| 部件 | 固定/活动 | 是什么 | 主要参数 |
|---|---|---|---|
| `Channel` | 固定 | 弹出侧的深槽 | `channel_w` / `channel_d` / `channel_h` |
| `Glow` | 固定 | 深槽里的发光条（等级色） | `glow_w` / `glow_d` / `glow_z` |
| `ChBolt` / `ChBoltT` | 固定 | 深槽两端的大螺栓 | `chbolt_x` / `chbolt_r` / `chbolt_cap_r` |
| `Plate` | **活动** | 板本体 | `plate_w` / `plate_thick` / `plate_margin` |
| `PlateEdge` | **活动** | 板边一圈金线 | `edge_outer` / `edge_inner` |
| `Arrow` | **活动** | 平嵌的箭头（等级色） | `arrow_len` / `arrow_shaft_w` / `arrow_head_len` / `arrow_head_w` / `arrow_sink` |
| `Leaf` | **活动** | 板面上的叶片 | `leaf_len` / `leaf_width` / `leaf_x` |

铰链位置 = 深槽中心 + `hinge_offset`。板子就绕这条线翻起，
所以改 `hinge_offset` 会同时改变板子的长度和翻转轴。

`arrow_sink` 控制箭头嵌进板面多深（现在只露 0.005，所以看着是"平嵌"）。

## 尖刺板 `spikes`

内板做成"井"字，中间空出四个方槽；刺从槽里升起，静止时刺尖齐板面。
三个等级**槽形完全一样**，只有刺的颜色不同。

| 部件 | 固定/活动 | 是什么 | 主要参数 |
|---|---|---|---|
| `Base` | 固定 | 砖体，实心，顶面就是槽底 | `base_depth` |
| `Plate` | 固定 | 浅灰内板的外圈 | `plate_inset` / `plate_rim` |
| `PlateCrossX` / `PlateCrossY` | 固定 | 十字隔条，和外圈一起围出四个方槽 | `cross_half` |
| `Liner` | 固定 | 槽壁的暗色内衬 | `liner_width` |
| `Spike` | **活动** | 锥体刺尖（等级色） | `cap_fill` |
| `SpikeShaft` | **活动** | 刺杆，静止时整根藏在砖体里 | `shaft_fill` / `shaft_len` |

> `Liner` 不能省。槽壁如果用浅灰内板本身，就只有槽底是暗的，深度完全读不出来。
>
> `cap_fill`（锥体宽度 ÷ 槽口宽度）之前给到 0.82，把槽底的深色全盖住了，
> 看上去就是四块平的青色方片。现在是 0.60。

`tip_below_plate` 控制静止时刺尖比板面低多少 —— 这个值保证"收起时不突出"。
`shaft_len` 只影响**弹出后**刺有多长，不影响静止外观。

## 推板 `push`（墙面，2:1）

原点在墙面上，本体往 +Y 伸出。`z_top - z_bottom = 0.5`、宽约 1.0，所以是 2:1。

| 部件 | 固定/活动 | 是什么 | 主要参数 |
|---|---|---|---|
| `Back` | 固定 | 贴墙的石底板 | — |
| `FrameT/B/L/R` | 固定 | 金框四条边 | `frame_w` |
| `LineT/B` | 固定 | 二级起金框上下的暗金细线 | — |
| `Bolt` | 固定 | 四角铆钉 | `bolt_r` / `bolt_h` |
| `GrooveT/B/L/R` | 固定 | 金框内沿的暗凹槽 | `groove_w` |
| `Bar` | 固定 | 左右两条发光竖条（等级色） | `bar_w` / `bar_inset` |
| `Panel` | **活动** | 中间的浅灰面板 | 由 `bar_inset` / `frame_w` 推出来 |
| `PanelEdge` | **活动** | 二级起面板外的一圈描边 | — |
| `Gem` | **活动** | 面板中央的宝石（等级色） | `gem_r` / `gem_inner` / `gem_h` |
| `PanelLeaf` | **活动** | 面板上的叶片 | `leaf_len` / `leaf_width` / `leaf_x` |

`front` 是金框正面离墙的距离。**面板静止时正面和它齐平**，改 `front` 会同时
影响金框厚度和面板位置。`Gem` 是唯一允许凸出的部件（设计图里就是一颗嵌上去的宝石）。

## 配色

配色表也在 `build_boards.py` 顶部（`COLORS` / `ACCENT`），但要注意一件事：

**这里写的是贴图色，不是屏幕上看到的颜色。** 游戏场景的环境光很亮，实测：

```
屏幕值 ≈ 0.31 + 0.71 × 贴图色
```

也就是存在一个 **0.31 的亮度地板** —— 按设计图吸到的槽色 0.23 直接填进去，
上屏是 0.475，一点都不暗。所以 `COLORS` 里的值是**反推**出来的：
目标屏幕值代入上式求解。改了环境光（`art.json` 的 `ambient_energy` / 色调映射）
以后这条拟合要重测。

`board_accent` 是等级色（1 青 / 2 紫 / 3 橙金），烘在模型里，Godot 不会覆盖它 ——
`traps.json` 的 `color` 只对老的机械造型机关（黏胶、锯墙）生效。

## 还没做的

**顶点 AO 还没烘。** 设计图的立体感有很大一部分是画上去的 AO：槽口边缘的暗角、
金框根部的接触阴影。现在这些模型完全没有 AO，全靠实时光照，而场景的 SSAO
半径是 1 米、槽才 0.12 米深，根本吃不进去。所以**就算部件尺寸全调对，
它还是会比设计图平** —— 形状定下来之后要单独做这一步。
